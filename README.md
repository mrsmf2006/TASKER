# TASKER

تسک‌منیجر شیءگرا. هر تسک از چند موجودیت سازمان — آدم، واحد، پروژه، دانش، منبع — ارث می‌برد، مثل یک نود در Geometry Nodes.

- مفهوم را مدیر تعریف می‌کند. نمونه (مثلاً علی) از آن ارث می‌برد، مقدارها را عوض می‌کند و پیشینه دارد (علی عضو واحد فنی است).
- با وصل شدن علی به یک تسک، پیشینه‌اش هم وارد زنجیرهٔ ارث می‌شود. ترتیب با همان الگوریتم C3 پایتون حساب می‌شود.
- اگر چند منبع یک ویژگی را بدهند (مثلاً ضریب سربار)، با قاعده‌ای که مدیر گذاشته ترکیب می‌شوند: ضرب، جمع، بیشینه، کمینه یا اولویت زنجیره.
- فرمول زمان و هزینه را مدیر می‌نویسد. با Done شدن تسک، بودجه و تجربه به‌روز می‌شود و یک خروجی دانش برای تسک بعدی آزاد می‌شود.

نسخهٔ منتشرشده: https://mrsmf2006.github.io/TASKER/

GitHub Pages همین شاخهٔ `main` را سرو می‌کند. `index.html` و `assets/` خروجی بیلد هستند؛ سورس صفحه در `index.dev.html` است. بعد از تغییر کد، `npm run build` همان فایل‌ها را تازه می‌کند.

```bash
npm install
npm test
npm run dev
npm run build
```
